# BIAP Iran x Hamkaran Systems: technical pilot concept (NOT an existing partnership)

Status as of 2026-10-28: proposal for discussion only. No signed agreement, API credentials, ERP connection, or data exchange. The Hamkaran Systems BI catalog already offers data integration, BI dashboards and a natural-language analyst (تحلیلیار); BIAP should not be marketed as replacing those capabilities.

**Differentiating research prototype:** An accountable multi-agent decision layer, with explicit independent agent votes, weight provenance, evidence gate and subsequent outcomes evaluation.

**Potential pilot, pending written authorization:**
1. Use an anonymized and consented read-only export from Rahkaran financial/receivables data, or a synthetic schema-approved sample; prohibit external financial data ingestion without agreement.
2. Implement ERP-specific agents (cash-flow, working capital, receivables quality, forecast, variance and risk). Do not use stock trading BUY/SELL actions as ERP operational actions.
3. Reconcile against known audited figures and document data lineage, missingness, uncertainty, explainability and a human-approval gate.
4. Pilot metrics: coverage, financial reconciliation rate, reviewer acceptance, forecast/calibration error, latency, and proportion of recommendations abstained from.
5. No production integration or co-branding until permissions, security, data processing and acceptance criteria are agreed.

**Scope of current code change:** Iran CODAL parser and Iran Kiasha quality gate / mobile transparency only. BIAP Global and existing portfolio snapshots remain untouched.
